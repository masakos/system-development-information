## コード設計

学生番号・商品コード・社員番号・注文番号など、システムで使う**番号（コード）のつけ方を決めること**を **コード設計** といいます。

### 1. コード設計の基本

| 注意点 | 内容 |
| --- | --- |
| **一意性** | 同じ番号が重複しない |
| **拡張性** | 人数や種類が増えても対応できる |
| **意味の持たせ方** | 番号に情報を含めるか、単純な連番にするか |
| **桁数** | 必要な件数を考えて決める |
| **可読性** | 人間が見て識別しやすい |
| **保守性** | 後からルールを変更しやすい |

---

### 2. 例：身近な番号の設計

| 番号 | 例 | 設計の特徴 |
| --- | --- | --- |
| **郵便番号** | `100-0001` | 番号に地域の意味がある |
| **ISBN** | `978-4-…` | 書籍を識別する国際的な番号 |
| **JANコード** | バーコードの13桁 | 商品を識別。最後の1桁は入力ミスを見つけるためのチェックディジット |

---

### 3. 設計クイズ

> **新しい専門学校のシステムを作ります。学生番号はどれにしますか？理由も答えよう。**
>
> - A：`00001`（単純な連番）
> - B：`260001`（入学年度＋連番）
> - C：`26-IT-001`（年度＋学科＋連番）



**「人間が見て分かりやすい番号」と「コンピュータが管理しやすい番号」は一致しない**ことがあります。
番号をつけるときは、**将来どんな変更が起きるか**まで考えて設計しましょう。
