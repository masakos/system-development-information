テスト 確認問題

組番名前

テストするプログラム（Purchase.java）

小計単価 × 数量
割引会員 かつ 小計が5000円以上 なら 500円、それ以外は 0円
支払金額小計 − 割引
public class Purchase {
    static int subtotal(int price, int quantity) {   // 小計
        return price * quantity;
    }
    static int discount(int subtotal, boolean member) {   // 割引
        int d = 0;
        if (subtotal >= 5000 && member) {
            d = 500;
        }
        return d;
    }
    static int pay(int price, int quantity, boolean member) {   // 支払金額
        int sub = subtotal(price, quantity);
        return sub - discount(sub, member);
    }
}
