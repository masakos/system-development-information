
CSV・XML・JSONは、いずれも**データをファイルなどに保存したり、システム間で受け渡したりするためのデータ形式**です。

# **1. CSV（Comma Separated Values）**

- 表形式のデータ
- CSVは、データをカンマ（`,`）で区切って表現する形式です。
- 例えば、学生情報をCSVで表すと次のようになります。

**students.csv**

```
id,name,age
1,田中,20
2,佐藤,19
3,鈴木,21
```

特徴：

- カンマで項目を区切る。
- Excelなどの表計算ソフトでも扱える。
- シンプルで、人間にも読みやすい。
- 複雑な階層構造を表現するのは苦手。


# **2. XML（eXtensible Markup Language）**

タグで構造を表現するデータ形式

XMLは、タグを使ってデータの意味や階層構造を表現する形式です。

例えば、学生情報をXMLで表すと次のようになります。

**students.xml**

```
<?xml version="1.0" encoding="UTF-8"?>
<students>
    <student>
        <id>1</id>
        <name>田中</name>
        <age>20</age>
    </student>
    <student>
        <id>2</id>
        <name>佐藤</name>
        <age>19</age>
    </student>
</students>
```

特徴：

- 開始タグと終了タグでデータを囲む。
- データの階層構造を表現できる。
- タグ名でデータの意味がわかる。
- CSVと比較すると記述量が多くなる。



# **3. JSON（JavaScript Object Notation）**

軽量なデータ交換形式

JSONは、JavaScriptのオブジェクト表記をもとにしたデータ形式です。

現在はWeb APIなどで広く使われています。

例えば、学生情報をJSONで表すと次のようになります。

**students.json**

```
{
  "students": [
    {
      "id": 1,
      "name": "田中",
      "age": 20
    },
    {
      "id": 2,
      "name": "佐藤",
      "age": 19
    }
  ]
}
```

特徴：

- `{ }` でオブジェクトを表す。
- で配列を表す。
- キーと値の組み合わせでデータを表現する。
- XMLより記述が簡潔。
- Web APIでよく利用される。

JSONの基本的なデータ型は次のとおりです。

| データ型   | 例                  |
| ------ | ------------------ |
| 文字列    | `"田中"`             |
| 数値     | `20`               |
| 真偽値    | `true`             |
| null   | `null`             |
| オブジェクト | `{ "name": "田中" }` |
| 配列     | `[1, 2, 3]`        |


# **4. CSV・XML・JSONの比較**

| 比較項目     | CSV        | XML       | JSON           |
| -------- | ---------- | --------- | -------------- |
| 表現方法     | カンマ区切り     | タグ        | キーと値           |
| 階層構造     | 苦手         | 得意        | 得意             |
| 記述量      | 少ない        | 多い        | 比較的少ない         |
| 主な用途     | 表計算・データ交換  | 文書・システム連携 | Web API・システム連携 |
