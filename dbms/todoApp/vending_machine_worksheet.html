自動販売機でUMLを描こうSTEP 0　観察しよう

解答（教員用）番号 氏名

いつも使っている 自動販売機 を、TODOアプリと同じように 3つの図 で表してみましょう。 図を描く前に、まずは「自動販売機で飲み物を買うとき、何が起きているか」を言葉にします。

STEPやること描くもの
0買うときの手順を言葉で書く文章
1手順を、順番・分かれ道・くり返しで表すアクティビティ図
2自動販売機を「部品」に分けるクラス図
3部品どうしの「頼みごと」の順番を表すシーケンス図
今回の場面：自動販売機に 200円 を入れて、150円の お茶 を買う

0-1　買うときの手順を完成させよう

図の自動販売機を見ながら、 に言葉を入れましょう。

  1. ① 客が自動販売機に お金を 入れる。
  2. ② 客がお茶の ボタン を押す。
  3. ③ 自動販売機がお茶の 在庫 があるか（売り切れでないか）確かめる。
  4. ④ 自動販売機が入れたお金が、お茶の 値段 以上か確かめる。
  5. ⑤ 自動販売機がお茶 を出す。
  6. ⑥ 自動販売機がおつり を返す。

0-2　ボタンを押しても、お茶が出てこないのはどんなとき？

思いつくだけ書こう（2つ以上）。 売り切れのとき お金が足りないとき （おつりが足りないとき）

0-3　手順の文から「名詞」と「動詞」を見つけよう

0-1 の文を読んで、名詞（もの・データ） と 動詞（すること） に分けて書きましょう。全部見つからなくてもOK。

名詞（もの・データ）動詞（すること）
例：お金 客 自動販売機 お茶 ボタン 在庫 値段 おつり 例：入れる 押す 確かめる 出す 返す

ヒント（手が止まったら、上から順に読もう）

  1. ヒント10-1：自販機で実際に買うところを、頭の中で1コマずつ再生してみよう。
  2. ヒント20-2：右の図の「水」を見てみよう。それから、100円しか入れなかったらどうなる？
  3. ヒント30-3：名詞は「〇〇が」「〇〇を」の〇〇に入る言葉。動詞は文の最後の「〜る」「〜す」の言葉。
この後のSTEPで使います
0-1 の 手順の順番→STEP 1 アクティビティ図
0-2 の うまくいかないとき→STEP 1 アクティビティ図の ◇（分かれ道）
0-3 の 名詞→STEP 2 クラス図の「クラス」と「属性」
0-3 の 動詞→STEP 2 クラス図の「メソッド」、STEP 3 シーケンス図の矢印

教員メモ

  • ねらい：図を描く前に、手順を言葉にする。名詞と動詞を分けておくと、STEP 2・3 が楽になる。
  • 0-1 は言い換えOK（「ボタン」→「商品のボタン」、「在庫」→「残り」など）。
  • 0-3 で名詞と動詞の区別がつかない生徒には「『〜する』『〜る』を付けて言えるのが動詞」と声をかける。

自動販売機でUMLを描こうSTEP 1　アクティビティ図

解答（教員用）番号 氏名

アクティビティ図は、処理の流れ（順番・分かれ道・くり返し） を表す図です。 STEP 0 の手順を図にします。①～⑥ に、下の「ことばカード」から選んで書き入れましょう。

ことばカード（1回ずつ使う）

おつりを返す 売り切れ？ 商品を出す お金は足りる？ 商品を選ぶ（ボタンを押す） おつりはある？

記号の読み方

開始
終了
すること（〜する）
分かれ道（〜？）
「はい」「いいえ」で進む先が変わる
上に戻る矢印は くり返し

ヒント

手が止まったら、上から1つずつ読もう。

  1. ヒント1STEP 0 の 0-1 の ①～⑥ と同じ順番で、上から並べよう。
  2. ヒント2◇（ひし形）には「？」で終わるカード、角の丸い四角には「〜する」のカードが入るよ。
  3. ヒント3② の「はい」の矢印は、① に戻っている。もう一度 ボタンを押し直す のはどんなとき？
  4. 最後③ の「いいえ」は、お金を入れる に戻る。お金を足すのはどんなとき？

問い

図の中で くり返し（上に戻る矢印）になっているのは何か所？ 2 か所

おつりがないとき（ちょうど150円を入れたとき）は、⑥ を通る？ 通らない

教員メモ

  • ねらい：「順番」「分かれ道（if）」「くり返し（for / while）」の3つで処理の流れが書けることに気づかせる。
  • ② と ③ の順番は、「はい」「いいえ」の矢印の戻り先で決まる。売り切れなら 選び直し（① へ）、お金が足りなければ お金を足す（「お金を入れる」へ）。
  • ⑤ の後の小さな ◇ は「合流」。分かれた道がここで1本に戻ることを説明する。
  • 早く終わった生徒には「0-2 で書いた『おつりが足りないとき』を図に描き足すと？」と問いかける。

自動販売機でUMLを描こうSTEP 2　クラス図

解答（教員用）番号 氏名

クラス図は、システムを 部品（クラス） に分けて、それぞれが 覚えておくデータ（属性） と できること（メソッド） を表す図です。 自動販売機を「自動販売機」と「商品」の2つのクラスに分けます。点線の行に「ことばカード」から選んで書き入れましょう。

ことばカード（1回ずつ使う）

値段 商品を選ぶ() 在庫を減らす() 商品リスト 在庫数 おつりを返す() 売り切れか() 商品を出す() 値段を返す()

問い

1. 線の両端の □ に、多重度を書こう。

自動販売機1台に、商品は何種類並んでいる？ → 商品の側に 0..*
お茶のボタン1つは、何台の自動販売機に付いている？ → 自動販売機の側に 1

2. STEP 0 の名詞のうち、クラスになったものは？ 自動販売機・お茶（商品）

属性になったものは？ お金（投入金額）・値段・在庫（在庫数）

記号の読み方

上の段クラス名
中の段属性（覚えておくデータ）
先頭の - は「外から直接さわれない」
下の段メソッド（できること）
先頭の + は「外から頼める」
1ちょうど1つ
0..*0こ以上（いくつでも）

ヒント

手が止まったら、上から1つずつ読もう。

  1. ヒント1「〇〇()」のように ( ) が付いたカードはメソッド（下の段）。付いていないカードは属性（中の段）。
  2. ヒント2迷ったら「それを知っているのはだれ？」と考えよう。お茶とコーラで 値段 は同じ？
  3. ヒント3在庫数 を持っているクラスが、「在庫を減らす()」「売り切れか()」も持つ。
  4. 最後自動販売機には、客が直接頼むこと（選ぶ・出す・返す）が入る。

教員メモ

  • ねらい：データと処理を「だれが持つか」で分ける。データ（在庫数）とそれを使う処理（在庫を減らす）は同じクラスに置く。
  • よくある間違い：値段・在庫数を自動販売機に入れる。→「値段を1つしか覚えられない自販機で、お茶とコーラを売れる？」と問いかける。
  • 多重度は「1..*」（商品が1つもない自販機はない）も正解。理由が説明できればOK。
  • TODOアプリとの対応：自動販売機 ＝ TodoApp（全体を管理する）、商品 ＝ Task（1つ1つのデータ）。

自動販売機でUMLを描こうSTEP 3　シーケンス図

解答（教員用）番号 氏名

シーケンス図は、だれが、だれに、どの順番で頼みごとをするか を表す図です。時間は 上から下へ 進みます。 点線の □ に「ことばカード」から選んで書き入れましょう。

ことばカード（1回ずつ使う）

在庫を減らす() 商品を選ぶ(お茶) おつりを返す() 売り切れか() 商品を出す() 値段を返す()

気づいた？ このカードは、STEP 2 のクラス図の メソッド と同じです。

問い

4 で、お茶が「はい（売り切れ）」と返事をしたら、この後どうなる？ STEP 1 の図で確かめよう。

5 から後は行われず、客が別の商品を選び直す（STEP 1 の ② →「はい」）

記号の読み方

頼む（メソッドを呼ぶ）
返事（戻り値）
┆ライフライン（時間の流れ）

ヒント

  1. ヒント1矢印には、矢印の先のクラスのメソッドを書く。お茶への矢印には「商品」クラスのメソッドが入る。
  2. ヒント24 と 6 の返事（点線）を見よう。「いいえ」「150円」は、何を聞かれた返事？
  3. 最後8・9 の自分に戻る矢印は、自動販売機が自分のメソッドを使うところ。お茶を出してから、おつり。

教員メモ

  • ねらい：シーケンス図の矢印 ＝ クラス図のメソッド。2つの図がつながっていることに気づかせる。
  • 矢印の向きで迷う生徒には「頼む側 → 頼まれる側」。頼まれた側（矢印の先）がそのメソッドを持っている。
  • 4・6・10 の点線は「返事（戻り値）」。Java の return にあたる。
  • アクティビティ図との違い：アクティビティ図は「何をするか」、シーケンス図は「だれがだれに頼むか」。
